The six forms that say it all

Past · Present · Future, said in two ways

1. The parallel

Every point in time can be said in two ways. Both are correct: use whichever comes out.

You already know the left column. The whole right column works the same way, because it is always built with one single pattern.

Look at the right column: the only thing that changes is the first word. Hablado, hablando and hablar never move.

4. The ones that break the rule

There are only a few. Learn them as words, not as a rule.

Irregular participles

  • abrir → abierto
  • decir → dicho
  • escribir → escrito
  • hacer → hecho
  • poner → puesto
  • ver → visto
  • volver → vuelto
  • romper → roto

Irregular gerunds

  • leer → leyendo
  • oír → oyendo
  • ir → yendo
  • dormir → durmiendo
  • pedir → pidiendo
  • decir → diciendo
Verb 2 ALWAYS ends in -o. It does not matter what gender or number you are talking about: there is no -a and no -os version.
