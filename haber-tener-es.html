El verbo auxiliar "haber"

Dos verbos que se suelen confundir. "HABER" es auxiliar o indica existencia. "TENER" indica posesión u obligación.

HABER → Auxiliar + impersonal

  • He comido → auxiliar (tiempos compuestos)
  • Hay un problema → uso impersonal
  • Hay muchos libros → uso impersonal, plural
  • Habéis cantado → auxiliar (vosotros)

TENER → Posesión y obligación

  • Tengo una máquina → posesión
  • Tiene frío → sensación física
  • Tengo hambre → sensación física
  • Tener que + infinitivo → otra forma de expresar obligación: Tengo que estudiar.
¡Ojo! "Tener" no siempre equivale a "sujetar" o "querer" en otros idiomas — cuidado con las traducciones literales de este verbo.
