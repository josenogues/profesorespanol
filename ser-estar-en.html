Ser y estar

SER = identity, origin, profession, time, permanent characteristics. ESTAR = temporary state, position, emotion, result of an action.

Spanish has two verbs for "to be", and they aren't used the same way. Neither is ever used as an auxiliary verb — for that, Spanish always uses HABER.

SER → Permanent identity, time, origin

  • Soy español → identity
  • Es rico → permanent trait
  • Son las tres → time
  • Es de Roma → origin

ESTAR → State or location

  • Estoy cansado → temporary state
  • Está en casa → location
  • Está rico → tastes good, not "rich"
  • ¿Cómo estás? → current state
Watch out! Es listo = he's clever (trait). Está listo = he's ready (state). The meaning changes!
